Inception

A small web infrastructure built for 42: each service runs in its own Docker container, built from its own Dockerfile, orchestrated with Docker Compose. This page is served by one of them.

Mandatory part

  • nginx - entry point, serves the WordPress site over HTTPS
  • wordpress - the site itself, running on php-fpm
  • mariadb - the database

Bonus part

  • redis - caches WordPress data in memory to speed up the site
  • ftp - upload files directly into the website's folder
  • static - this page (plain HTML/CSS, no PHP)
  • adminer - web interface to browse the database
  • backup - dumps the database every hour, keeps the last 7
